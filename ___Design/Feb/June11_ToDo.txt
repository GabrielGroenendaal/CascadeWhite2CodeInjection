Move Change Ideation: 
    - Existing Move Changes: 
        - GRASS KNOT becomes a trapping move. It still deals damage based on weight but deals max damage on a target switching out.
        - LOW KICK becomes a trapping move. It still deals damage based on weight but deals max damage on a target switching out.
        - ROLLING KICK becomes a 90 BP Fighting move with a 30% chance to flinch. This becomes excellent for Hariyama. 
        - NIGHT DAZE is so strong I hesitate to give it to anyone basically. 
    - Move Revival: 
        - SACRED FIRE
            - A powerful physical fire move with a scary secondary effect is neat. 
            - It would overlap a bit with our Blaze Kick tho. 
            - Would suit a bunch of fire types that can't fucking kick or punch well tho: 
                - Solrock if we made it physical 
                - Ninetales as a serene grace tech 
                - Rapidash as a scale move 
        - ICE BALL
            - I kinda like what PK did making it a physical single target Blizzard. 
            - That has a ton of cool use cases; it could be an early low accuracy move for Dewong 
            - Surprising number of interesting mons get it: Qwilfish, Licklicky, Poliwrath, Steelix, Snorlax, Electrode, Swampert 
        - SYNCHRONOISE
            - I think there are a lot of ways to make this move interesting. 
            - Maybe it always deals super effective damage on pokemon you share a type with.
            - Super cool for Hypno and would be cool for psychic types to hurt themselves. 
            - Reflect Type synchronoise would be sick.
            - Spacial Redn could be a cool psychic physicall move ngl.
        - ICE BURN / FREEZE SHOCK I don't need both Ice burn and freeze shock but i think i need one of them for my finale. I can make it giga busted 
        - SPIDER WEB; following the tradition of my other changes, maybe make it spread and drop speed by two stages. 
        - MIND READER / LOCK ON: I like the idea of these moves maybe providing large accuracy boosts. Not that crazy in isolation but they can support chain kills and also make stored power more useful without being overwhelming. Providing an automatic crit could also be cool.
        - SMELLING SALTS could have something interesting done with it
        - TRUMP CARD already has a cool mechanic with no uusers. It'd be insane on the -ate/-ize Eeveelutions. 
        - WRING OUT could maybe be something? Interesting distribution again. 
        - CRUSH GRIP as a giga scary trapping move is cool. 
        - SPITE functioning like eerie spell and becoming an early game special ghost move is cool, especiallly because it would free up astonish and lick. I really like PK making lick 80 BP. It would also mean not everyone needs to learn hex. 
        - SOMETHING could maybe be done with memento? I'm not sure what that wouldn't break the game tho. 
    - Moves I don't use that much: 
        - VICTORY DANCE: I just feel bad putting this on any mon. It doesn't feel earned whatsoever. It feels artificial in its construction. 
        - BESTOW: I've been using this as a blank space but I can absolutely just zero out handler fields. 
        - BITTER MALICE: This one is really disappointing. To be honest, I might just move seething cold effect to this. An ice-type hex seems so promising but i never keep it on anything. Maybe instead it should become 75 BP ghost move that lowers spA? What's the animation even right now.

    extern "C" void HandlerCollective(BattleEventItem * item, ServerFlow * serverFlow, u32 pokemonSlot, u32 * work) {
        if (pokemonSlot == BattleEventVar_GetValue(VAR_MON_ID)) {
            BattleMon* currentMon = Handler_GetBattleMon(serverFlow, pokemonSlot);

            //  0: Combee-Male 
            //  1: Combee-Female 
            //  2: Combee-Collective
            // 26: Unown-Exclamation 
            // 27: Unown-Question 
            // 28: Unown-Exclamation Schooling 
            // 29: Unown-Question Schooling

            u8 currentForm = BattleMon_GetValue(currentMon, VALUE_FORM);
            u8 newForm = currentForm;
            u16 msgID = BATTLE_SCHOOLING_INACTIVE_MSGID;

            // TODO: ADD WISHIWASHI
            if (BattleMon_GetSpecies(currentMon) == 201) {
                u32 currentHP = BattleMon_GetValue(currentMon, VALUE_CURRENT_HP);
                if (currentForm == 26 || currentForm == 27){
                    if (currentHP > DivideMaxHPZeroCheck(currentMon, 4u)) {
                        newForm = currentForm - 2;
                        msgID = BATTLE_SCHOOLING_ACTIVE_MSGID;
                    }
                }
                if (currentForm == 28 || currentForm == 29){
                    if (currentHP <= DivideMaxHPZeroCheck(currentMon, 4u)) {
                        newForm = currentForm + 2;
                        msgID = BATTLE_SCHOOLING_INACTIVE_MSGID;
                    }
                } 
            }

            if (BattleMon_GetSpecies(currentMon) == 415) {
                u32 currentHP = BattleMon_GetValue(currentMon, VALUE_CURRENT_HP);
                if (currentForm == 0){
                    if (currentHP > DivideMaxHPZeroCheck(currentMon, 4u)) {
                        newForm = currentForm + 2;
                        msgID = BATTLE_SCHOOLING_ACTIVE_MSGID;
                    }
                }
                if (currentForm == 2){
                    if (currentHP <= DivideMaxHPZeroCheck(currentMon, 4u)) {
                        newForm = currentForm - 2;
                        msgID = BATTLE_SCHOOLING_INACTIVE_MSGID;
                    }
                } 
            }


            if (currentForm != newForm) {
                    HandlerParam_ChangeForm* changeForm;
                    changeForm = (HandlerParam_ChangeForm*)BattleHandler_PushWork(serverFlow, EFFECT_CHANGE_FORM, pokemonSlot);
                    changeForm->header.flags |= HANDLER_ABILITY_POPUP_FLAG;
                    changeForm->pokeID = pokemonSlot;
                    changeForm->newForm = newForm;
                    BattleHandler_StrSetup(&changeForm->exStr, 2u, msgID);
                    BattleHandler_PopWork(serverFlow, changeForm);
                }

        }
    }
    BattleEventHandlerTableEntry CollectiveHandlers[]{
        {EVENT_SWITCH_IN, HandlerCollective},
        {EVENT_TURN_CHECK_DONE, HandlerCollective},
    };
    extern "C" BattleEventHandlerTableEntry * EventAddZenMode(u32 * handlerAmount) {
        *handlerAmount = ARRAY_COUNT(SchoolingHandlers);
        return CollectiveHandlers;
    }
