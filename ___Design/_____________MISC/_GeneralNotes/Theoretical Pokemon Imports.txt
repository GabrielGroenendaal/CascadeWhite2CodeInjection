Generation 6: 
    
    Best Options: 
        Greninja 
        Chesnaught 
        Delphox 
        Pangoro
        Swirlilx / Slurpuff 
        Dragalge 
        Heliolisk 
        Amaura / Aurorus 
        Sylveon 
        Noivern 
        Trevenant 
        Gourgeist 
    
    Reasonings:
        Chesnaught 
            + Bulky grass fighting is cool 
            + Iron Barbs and Bulletproof are cool 
        
        Greninja
            + Great for the Shadow Triad to have. 
            + Cool torrent abuser  
            + Infiltrator?
            - Speed creep and power creep. 
        
        Delphox: 
            + Unique typing, not counting Darm-Z 
            + Very fitting on a lot of mons, including Shauntal maybe as a mgic guard mon. 
        
        Talonflame 
            + Unique typing, pretty cool bird without overwhelming attack 
            - I wouldn't want to implement Gale Wings 
        
        Pangoro: 
            + Adds a more offensive dark/fighting type 
            + Really cool mon for grimsley. I could see a quick claw iron fist Pangoro with wicked blow/dynamic punch/ice hammer/meteor mash 
            - Doesn't super fit in anywhere as a local mon 
        
        Swirlix / Slurpuff 
            + Cool early game fairy, not overwhelming stats 
            + Good for the Pokestar Studios encounter table and the Preschool table 
            - Takes two slots 
            - Competes with other cool early fairies 
        
        Dragalge 
            + Covers a very cool niche of poison/dragon, might be able to free Gorebyss from that role 
            + Bulky which is a cool stat profile 
            - Takes two slots 
        
        Helioeptile / Heliolisk 
            + A cool normal/electric with a lot of weather synergies. 
            + not overwhelming offense or speed. 
            - takes two slots 
        
        Amura / Aurorus 
            + would be a very cool ice/electric mon 
            + adding another fossil would be cool, especially one we can put in early. 
            - takes two slots 
        
        Sylveon
            + I would kinda have to for completeness sake 
            + It's a cool mon for enemies to have. 
            + tbh i might be doing this anyways 
        
        Gourgeist: 
            + Covers a missing typing, and we could free cacturne of that role 
            + We can make use of forms to give it a lot of different cool statlines. 

        
        Trevenant: 
            + Basicallly the same situation as Grougeist, altho it's a weaker mon.
            - Has less interesting ability and tech 
        
        Noivern: 
            + Obviously very cool mons that would get to be pretty cool in Cascade. 
            + Amplifier helps them, so does infilitrator. 
            + Cool mon for musicians and dancers to have. 


Generation 7: 

    Best Options: 
        Type Null / Silvally 
        Crabrawler / Crabominable 
        Rockruff / Lycanroc 
        Sandyghast / Pallosand 


    Reasonings: 
        
        Decidueye: 
            + 1 slot 
            + Lots of cool buff ideas, even a simple speed boost. AI could have sniper. 
            - I don't want to implement spirit shackle. 
        
        Crabrawler / Crabomainable 
            + Very cool mons 
            + Cool typing, might actually free up Beartic to go Ice/Dark perhaps 
            + Lots of cool abilities concepts; iron fist, fur coat, etc. 
            + fits for a lot of different trainers, more fishing table diversity. 
            - takes two slots, although we don't *need* crabrawler 
        
        Rockruff / Lycanroc: 
            + cool mon to put in pledge grove 
            + get a lot of mileage out of the different forms with no extra head ache. 
            + each form has a lot of options for cool niches. 
        
        
        Sandyghast / Pallosand: 
            + Cool mon, special ground/ghost isn't covered 
            + Another good pokemon for fisherman 
            + Works really welll as a fishing table mon. 
        
        Type Null / Silvally: 
            + Probably won't need both of these, but they both work really well for Colress. 
            + type null gift would work quite well for the player actually.
